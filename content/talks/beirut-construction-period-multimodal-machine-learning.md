This seminar presented an artificial-intelligence framework for automated characterization of building construction periods in Beirut, supporting city-scale seismic risk and vulnerability assessment.

The work compared street-view image modelling, tabular modelling, and a late-fusion multi-modal model. The multi-modal model achieved the best performance and was used in a toy example to predict building construction periods and assess earthquake vulnerability in a Beirut neighborhood.
