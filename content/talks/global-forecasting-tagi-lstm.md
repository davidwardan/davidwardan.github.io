This seminar explored the application of global modelling with TAGI-LSTM, how it compares to state-of-the-art models, and its potential advantages.

The talk contrasted local forecasting, where a distinct predictive model is trained for each time series, with global forecasting, where a single predictive model is trained using multiple time series.
